# Radar Diario

App web (PWA) con noticias diarias de cultura gamer, desarrollo de videojuegos y 3D, animación y VFX, diseño UI/UX, IA y deportes (Liga MX, Premier, LaLiga, Serie A, Champions y NFL), con Mis equipos: Rayados, Liverpool y Vaqueros.

- Se publica con GitHub Pages: https://abrahamlozano.github.io/radar-diario/
- `data.json` se actualiza cada noche (9:36 pm, hora del centro de México) con la tarea programada de Claude.
- `index.html` + `app.js` son la interfaz; `sw.js` permite abrirla sin conexión con la última edición descargada.

Para instalarla en el celular: abre la dirección en Safari (iPhone → Compartir → Agregar a pantalla de inicio) o Chrome (Android → ⋮ → Instalar app).
